# Дневник тренировок

Статическое PWA для Android. Откройте приложение через HTTPS. В разделе «Данные» импортируйте свой персональный JSON. Записи хранятся в браузере. Для резервного копирования используйте экспорт JSON.

Для GitHub Pages выберите ветку main и каталог / (root). На Android в меню Chrome выберите установку приложения или добавление на главный экран.
